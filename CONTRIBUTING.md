# Contribution policy

NEXO uses a **restrictive source-available license**, not an OSI-approved
open-source license. Issue reports, benchmark data, questions and citations
are welcome.

The public license does not authorize publishing a modified NEXO fork or
patch. For code contribution, first obtain explicit written permission
from the copyright holder and agree any necessary contribution rights.
Opening a GitHub pull request does not itself create an exception.

Benchmarks should provide the corpus, JSON baseline, tokenizer identity and
version, full message framing and both positive and negative results.

## Documentation language

Write README content, reference documentation, code comments, commit/PR
summaries, example descriptions, and user-facing diagnostics in **English**.
Non-English and Unicode strings are allowed in protocol conformance tests
where they exercise UTF-8 behavior; do not translate or remove those vectors.
